# ERP 2026-11-01 更新说明

## 业务改进

- 客户与供应商联系信息拆分权限；销售仅可查看、维护本人建立的客户联系信息。
- 超级管理员可在库存批次页核对原数量、输入调整数量及原因，经密码二次验证后调整，并留下库存流水和审计记录。
- 客户退货增加待审核单据的通过、驳回入口；销售、采购、生产对账入口与业务岗位对应。
- 成品可选择“外购转售”，无需 BOM 或生产领料，销售优先检查成品库存。
- 新建生产指令支持模糊搜索成品，并自动列出可用 BOM。
- 送货单支持 241 x 140 mm、半 A4、A4 和自定义纸张，支持偏移校准及明细分页；预览不记录打印，正式打印按钮才记录发起。
- 页面版本优先读取安装包的 VERSION，避免旧 .env 版本号遮蔽更新。

## 安装与升级

- 全新安装包包含程序、离线 Python 依赖和前置工具安装程序；运行 ERP-Setup.exe 前，先安装 Python 3.12、PostgreSQL 17，并确认 PostgreSQL 服务运行。NSSM 已随包提供，Git 非必需。
- 增量升级包仅用于已有完整 ERP 安装的机器。先备份数据，解压整个升级包，在包内运行 ERP-Update.exe；默认安装目录为 D:\ERP\app。
- 升级程序先校验包内文件哈希，再停止服务、备份应用、覆盖变更文件、执行迁移和系统检查。保留 .env、数据库、附件、日志与虚拟环境。
- 针式三联纸在打印机驱动中设置与页面一致的纸张尺寸，正式打印份数设为 1；首次使用先打印校准页。实际走纸和三联压印效果需要现场确认。
